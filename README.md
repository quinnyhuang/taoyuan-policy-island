# 桃園政策島｜黃世杰．心桃園動起來

**網站：https://quinnyhuang.github.io/taoyuan-policy-island/**

製作：Quinny

非官方的互動 3D 政策島，整理 2026 桃園市長參選人黃世杰公開發表的政見。

- 操控小企鵝走訪六座政見島與四座延伸島（蜂巢式排列，拱橋相連），島上標著 ①②③ 的建築與道具就是每項政見的具體目標
- 12 位虛構市民用自己的生活情境介紹政見；四姐（依候選人形象設計的角色）在各島肥皂箱之間巡迴，可以請他叫公車載你去別座島
- 右上角「沙盤」可切換俯瞰模式，拖曳、縮放整座島群
- 每張政見卡都附公開報導出處與日期

## 聲明

- 本站**不是**候選人、政黨或競選團隊的官方網站。
- 市民角色均為虛構，台詞轉述自公開報導；四姐的台詞由本站撰寫，不是候選人本人發言。
- 政見內容依新聞報導整理，未加引號者為報導轉述；標示「競選方」的數字由候選人陣營引述，本站未另行查證。

## 技術

單一 `index.html`，使用 [three.js r128](https://threejs.org/)（cdnjs 載入）與 Google Fonts（Huninn、Noto Sans TC），不需建置流程。直接用瀏覽器開啟，或用 GitHub Pages 發布即可。
